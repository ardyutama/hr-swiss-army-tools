# Business Process — As-Is and To-Be

## Current workflow (as-is)

> HR wants to check CVs → open all emails → filter, or just check the ones with a fitting
> subject → review one by one and open each PDF → take notes or mark something → continue
> to the next CV.

Characteristics of the current process:

- Fully manual and repeatable.
- CVs are sorted one by one.
- Notes/marks are taken outside any system.
- No easy path from "chosen CV" to "contact the talent".

## What we want to solve (to-be)

### 1. Shorten the one-by-one review path

Remove the manual email-hopping steps. HR should not need to open every email, filter by
subject, and open each PDF individually just to start reviewing.

### 2. Easy-to-view CV review workspace

A tidy and straightforward review workspace reduces effort — the CV is already open, and
notes are already attached to it in the same place.

### 3. Contact talent

When a CV / talent has been chosen, HR can create a **message template** and send a message
based on the resume — directly from the tool.
