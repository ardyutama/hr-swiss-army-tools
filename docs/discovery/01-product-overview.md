# HR Swiss Army Tools — Product Overview

## What the app is going to be

A tool for **sorting and reviewing CVs in traditional companies** that still receive
applications **by email** in non-ATS formats (PDF, design-heavy resumes, free-form layouts),
instead of through a modern Applicant Tracking System (ATS).

## Why this matters

Traditional companies still use non-ATS CVs because their **fieldworker environment has not
been exposed to modern ATS tooling**. Existing tools on the market are built for modern ATS
workflows only, leaving this segment unserved.

## Pain points today (non-ATS CV sorting)

- **Hard to read** — CVs arrive in mixed, unstructured formats.
- **Design-heavy CVs** ("design sentris") — visually styled resumes that don't parse cleanly.
- **All existing tooling targets modern ATS only** — nothing fits this workflow.
- **Repeatable yet manual** — the same sorting steps are repeated by hand for every CV.
- **Mixed variety of job requirements** — one inbox serves many different positions.
- **By email** — CVs arrive as email attachments, not in a structured pipeline.
- **Sorted one by one** — each CV is opened, reviewed, and marked individually.

## Current HR environment (design constraints)

1. **Windows environment** with users who have no IT background.
2. Needs **straightforward instructions with no setup overhead**.
3. Further requests or updates must **integrate right away with just a click**.
4. Must be **fast and get the job done**.
